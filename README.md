# 57 ГРАНЕЙ

Мобильное приложение для сети стоматологических клиник **«57 ГРАНЕЙ»**, разработанное на Flutter для iOS и Android.

Проект объединяет три пользовательских сценария в одном приложении: кабинет пациента, кабинет врача и административную часть.

> Проект находится на стадии функционального demo/MVP.  
> Интерфейс и основные пользовательские сценарии реализованы, данные в текущей версии работают на локальном demo-слое. Серверная часть планируется отдельным этапом.

## Возможности

### Пациент

- вход и регистрация по номеру телефона;
- подтверждение номера;
- оформление согласия на обработку персональных данных;
- главная страница пациента;
- выбор клиники;
- запись на приём;
- просмотр предстоящих и прошедших записей;
- информация о врачах;
- документы и рекомендации;
- уведомления;
- профиль пациента;
- карта и навигация до клиники.

### Врач

- отдельный вход для сотрудников;
- авторизация врача;
- персональное расписание;
- календарь рабочих дней;
- список приёмов;
- просмотр карточки записи и данных пациента;
- отображение свободных дней.

### Администратор

- административный интерфейс;
- управление врачами;
- управление доступом врачей в приложение;
- создание и изменение demo-учётных данных;
- включение и отключение доступа;
- управление публикациями приложения.

## Запуск проекта

Установить зависимости:

```bash
flutter pub get
```

Для функций карты требуется собственный API-ключ Yandex MapKit.

Создайте локальный файл:

```text
.mapkit.env
```

и добавьте:

```text
MAPKIT_API_KEY=your_api_key_here
```

Файл `.mapkit.env` является локальным, не входит в Git и не должен публиковаться.

Запуск приложения:

```bash
flutter run --dart-define-from-file=.mapkit.env -d <device-id>
```

Release-запуск:

```bash
flutter run --release \
  --dart-define-from-file=.mapkit.env \
  -d <device-id>
```
