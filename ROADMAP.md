# 57 ГРАНЕЙ — Roadmap

Текущая цель — завершить стабильную интерактивную demo-версию для iOS и Android, а затем перейти к backend, реальным данным и production-инфраструктуре.

## Demo Stabilization

После завершения основных экранов:

- [ ] пройти Patient / Doctor / Admin сценарии end-to-end;
- [ ] проверить приложение на реальных iOS и Android устройствах;
- [ ] устранить оставшиеся визуальные расхождения с Figma;

- [ ] подготовить стабильную demo-сборку.
