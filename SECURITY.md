# Security Policy

## Назначение репозитория

Это публичная demo/MVP-реализация мобильного приложения. В репозитории не
должно быть реальных данных пациентов, сотрудников, медицинских документов,
API-ключей, паролей или личных контактных данных.

Все имена, телефоны, учётные записи и медицинские сценарии в приложении являются
демонстрационными.

## Сообщить об уязвимости

Не публикуйте сведения об уязвимости в открытом issue. Используйте приватную
форму GitHub Security Advisories:

https://github.com/ip52rus/grani57_app/security/advisories/new

В сообщении укажите затронутый компонент, сценарий воспроизведения и возможное
влияние. Не прикладывайте реальные персональные или медицинские данные.

## Локальная конфигурация

Секреты передаются только через локальные файлы, исключённые из Git, или через
защищённые secrets CI. Для Yandex MapKit используется `.mapkit.env`.
